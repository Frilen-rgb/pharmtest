# ФармТест

Учебный тренажёр по 17 темам фармакологии. В каждом тематическом разделе можно пройти все вопросы по теории и препаратам или выбрать 30 случайных вопросов из того же банка. Порядок вопросов и вариантов ответа меняется с каждой попыткой.

После основных тем расположен отдельный блок «Дополнительные конспекты» с янтарными карточками. В нём шесть самостоятельных разделов по новым документам:

| Раздел | Вопросов |
| --- | ---: |
| Анальгетики и психотропные препараты | 66 |
| Средства для общего наркоза | 50 |
| Анальгетики и психотропные средства - повторение | 54 |
| Давление, РААС и диуретики | 56 |
| Адренорецепторы и вегетативные эффекты | 55 |
| Холиномиметики и холинолитики | 56 |

Всего в курсе 1337 вопросов. В новых темах также есть полный тест и случайная подборка из 30 вопросов. Они входят в смешанный тест. Неоднозначные названия из конспектов отмечены в пояснениях, без выдуманной расшифровки.

В разделе «Эфферентная нервная система» под выбором теста можно открыть фотографию таблицы «Симпатика и парасимпатика» с пояснениями к отдельным строкам.

В разделе «Определения» 38 вопросов из файла к зачёту. К каждому определению нужно подобрать один из четырёх терминов.

В разделе «Препараты и их группы» можно пройти весь банк из 584 вопросов или случайную подборку из 40. При каждом новом запуске подборка формируется заново. В полном тесте перемешивается порядок всех вопросов. Прогресс сохраняется отдельно для каждого формата.

В смешанном тесте 60 случайных вопросов по определениям, препаратам, фармакологическим эффектам, показаниям и побочным эффектам. Вопросы берутся из каждого конспекта и файла с определениями. Ответы и пояснения появляются после завершения попытки. По итогам любого теста Феско оставляет сообщение. Вопросы с ошибками и пропусками можно пройти ещё раз.

Во время теста можно начать заново или завершить попытку досрочно. При перезапуске вопросы и варианты перемешиваются. При досрочном завершении выбранный вариант текущего вопроса учитывается, а вопросы без ответа отмечаются в разборе. Результат рассчитывается по всем вопросам попытки.

По умолчанию включена ночная тема. Переключатель в верхнем меню меняет тему. Браузер запоминает выбор.


## Пять типов вопросов

В каждую из 17 тем добавлено 10 вопросов: по два определения, вопроса о препаратах, фармакологических эффектах, показаниях и побочных эффектах. Всего добавлено 170 вопросов. К определению нужно выбрать подходящий термин; остальные задания проверяют группу и свойства препарата, его действие, цель применения или нежелательную реакцию. Каждый вопрос содержит четыре разных варианта и пояснение.

Новые случайные подборки из 30 вопросов по теме и 40 вопросов по препаратам включают все пять типов. В смешанном тесте сохраняется представительство каждой темы и определений, одновременно присутствуют все пять типов вопросов. Ответы в смешанном тесте по-прежнему открываются только в конце. Внутри вопроса тип отмечен небольшой подписью. В полном тесте остаются также все ранее добавленные вопросы.

Сохранённые попытки со старым количеством вопросов можно продолжить до конца. Новые вопросы появляются в новой попытке через «Начать заново». Результаты прежних прохождений и личные тесты сохраняются.

Показания и побочные эффекты уточнены по инструкциям к препаратам из конспектов. Дозировки и схемы назначения не добавлялись. Список источников дополнения находится в [SOURCES.md](SOURCES.md).

## Звуки и эффекты

После верного ответа звучит короткая мелодия и появляется анимация отметки. После ошибки звучит мягкий понижающийся сигнал, карточка ответа слегка покачивается. Серия из трёх и более верных ответов отмечается подписью. Завершение теста сопровождается отдельной мелодией; при всех верных ответах появляется короткое конфетти.

Кнопка с динамиком в верхнем меню включает и выключает звук. Выбор запоминается в этом браузере. Звуки создаются самим сайтом и работают без загрузки аудио из сторонних сервисов. Они запускаются после действия пользователя. При перезагрузке или открытии сохранённого результата мелодия повторно не воспроизводится.

В смешанном тесте до завершения звучит одинаковый нейтральный сигнал сохранения ответа. Звук и анимация не сообщают, верен ли выбранный вариант. При включённом уменьшении движения в настройках устройства анимации ответа и конфетти отключаются. Иллюстрация с капсулой остаётся статичной.

В учебных вопросах, вариантах и пояснениях используется название группы «нейролептики». Идентификаторы вопросов и порядок правильных вариантов сохранены, поэтому старые ответы продолжают открываться.

## Запуск на компьютере

Распакуйте архив целиком и откройте `index.html` в браузере. Для сайта достаточно файлов из архива. Все ресурсы подключены относительными путями, поэтому сайт работает и в подпапке репозитория.

## Публикация на GitHub Pages

1. Добавьте содержимое распакованного архива в корень репозитория, включая файл `.nojekyll` и папку `assets`.
2. Откройте настройки репозитория **Settings → Pages**. В блоке **Build and deployment** выберите **Deploy from a branch**.
3. Укажите ветку, в которую добавили файлы, например `main`, и папку `/(root)`. Нажмите **Save**.
4. После публикации откройте адрес сайта в разделе **Pages**.

[Инструкция GitHub Pages](https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site)

Для обновления действующего сайта распакуйте новый архив. В корне того же репозитория откройте **Code → Add file → Upload files**, загрузите содержимое архива с теми же путями и сохраните изменения в ветке публикации. Например, фотография должна появиться в `assets/efferent-notes.png`. GitHub Pages опубликует новый коммит по прежнему адресу.

## Вопросы и прогресс

Вопросы по теории находятся в `questions.js`, вопросы по препаратам - в `drugs.js`, термины для зачёта - в `definitions.js`, новые разделы - в `supplement-a.js` и `supplement-b.js`, дополнение по пяти типам вопросов - в `coverage.js`. Сохраняйте идентификаторы вопросов при правке формулировок, чтобы текущие попытки продолжали открываться.

При первом открытии сайта нужно назвать профиль или восстановить его по коду. После создания показывается уникальный 16-символьный код и кнопка копирования. Сохраните его в заметках. Профили не удаляются при обновлении сайта, перезапуске браузера или переключении между ними. На одном устройстве можно завести несколько профилей в меню «Прогресс».

У каждого профиля свои начатые тесты, ответы, результаты, личные тесты и черновик. Другие посетители сайта их не видят. Вкладка «Мои тесты» открывает коллекцию активного профиля. Нажмите «Создать тест», добавьте название, вопросы и минимум четыре разных варианта ответа на каждый вопрос. Кружком отмечается один верный ответ. Можно добавить до восьми вариантов, пояснение, новые вопросы и поменять их порядок. Черновик автоматически сохраняется при вводе. Нажмите «Сохранить тест», чтобы перейти к прохождению.

Личные тесты можно редактировать или удалять. В них также перемешиваются вопросы и ответы, сохраняется попытка, доступно досрочное завершение и повторение ошибок. Изменение только названия или описания сохраняет результаты. Изменение вопросов начинает статистику этого теста заново. Личные вопросы не попадают в общий смешанный тест.

Данные сохраняются в браузере для текущего адреса сайта. Очистка данных сайта, приватный режим, удаление браузера или смена адреса могут сделать местные сохранения недоступными. Если браузер запретил сохранение, сайт показывает соответствующее сообщение. Не используйте приватный режим для постоянного профиля.

При наличии интернета сервис автоматически обновляет резервную копию, связанную с кодом профиля. В ней сохраняются прогресс, личные тесты и черновик. Проверить состояние можно во вкладке «Мои тесты» или через «Прогресс → Код и резервная копия». Перед закрытием страницы после важных изменений дождитесь надписи «Резервная копия обновлена».

Для восстановления выберите «Восстановить по коду» при первом входе или «Прогресс → Добавить по коду». По коду загружается последняя успешно сохранённая копия. Восстановленный профиль становится отдельной местной копией и получает свой новый код, который тоже нужно сохранить. Копии не синхронизируются между собой. Так можно передавать профиль с тестами, сохраняя управление исходным профилем у его владельца. Каждый, кто знает код, может получить копию, поэтому передавайте его только нужным людям.

Обмен по коду требует интернета. Версия для GitHub Pages обращается к сервису опубликованного ФармТеста. Сам GitHub Pages не хранит резервные копии. Для переноса на адрес GitHub Pages сначала дождитесь успешного резервного копирования на старом адресе, затем добавьте профиль по коду на новом.

## Справочники по классификации

- Лерканидипин относится к дигидропиридиновым блокаторам кальциевых каналов. [ATC C08CA13](https://atcddd.fhi.no/atc_ddd_index/?code=C08CA)
- Толперизон относится к миорелаксантам центрального действия. [ATC M03BX04](https://atcddd.fhi.no/atc_ddd_index/?code=M03BX)
- Рифампицин относится к рифамицинам. [Инструкция по медицинскому применению](https://www.rlsnet.ru/drugs/rifampicin-2678)
- Симпатическая и парасимпатическая стимуляция по-разному влияют на мышцы мочевого пузыря. [Обзор в BJA Education](https://www.ucl.ac.uk/anaesthesia/sites/anaesthesia/files/bankenahally-2016-ans.pdf)
- Мускариновая стимуляция ресничной мышцы может облегчать отток внутриглазной жидкости. [Инструкция пилокарпина](https://dailymed.nlm.nih.gov/dailymed/drugInfo.cfm?setid=84428e9a-f486-44d9-ad93-4ea9069a6787)
- Ликферр100 содержит железа сахарозный комплекс. [Справочник РЛС](https://www.rlsnet.ru/drugs/zeleza-saxaroznyi-kompleks-78707)
- В классификации слабительных лактулоза относится к осмотическим средствам. [Инструкция лактулозы](https://dailymed.nlm.nih.gov/dailymed/drugInfo.cfm?setid=d6975cd8-80e0-43e2-809a-175ea7e40715)
- Зиртек и обычный Зодак содержат цетиризин. [Листок-вкладыш Зиртека](https://assets.gskstatic.com/pharma/PM-PI_portal/Kazakhstan/zyrtec_tablets_kz_ru.pdf), [листок-вкладыш Зодака](https://zodac.allergia.pro/upload/Zodac%20fct%2010%20mg%20%28cetirizine%29_Approved%20PIL-L-23.01.2024.pdf)
